# Mes Voyages - Application PWA

Application de gestion de voyages (hébergement et transport) sous forme de Progressive Web App (PWA) compatible Android.

## Fonctionnalités

- **Tableau de bord** : Liste des voyages à venir et passés.
- **Création de voyage** : Ajouter un nouveau voyage avec dates et destination.
- **Détails du voyage** : Vue chronologique (Timeline) des transports et hébergements.
- **Ajout d'éléments** : Formulaires détaillés pour ajouter des transports (Train, Avion, Bus) et des hébergements.
- **Mode Édition** : Modifier ou supprimer des éléments et des voyages.
- **Persistance des données** :
    - Par défaut : LocalStorage (navigateur).
    - Optionnel : Base de données Supabase (Cloud).
- **PWA** : Installable sur Android via Chrome.

## Installation et Lancement

1.  **Cloner le dépôt**
    ```bash
    git clone <votre-repo>
    cd <votre-repo>
    ```

2.  **Installer les dépendances**
    ```bash
    npm install
    ```

3.  **Lancer le serveur de développement**
    ```bash
    npm run dev
    ```

## Configuration Base de Données (Supabase)

Par défaut, l'application utilise le `localStorage` de votre navigateur. Pour synchroniser vos données entre plusieurs appareils, vous pouvez connecter une base de données Supabase.

### Étape 1 : Créer un projet Supabase

1.  Allez sur [supabase.com](https://supabase.com/) et créez un compte.
2.  Créez un nouveau projet ("New Project").
3.  Notez l'URL du projet et la clé publique `anon` (disponibles dans *Settings > API*).

### Étape 2 : Configurer les variables d'environnement

1.  À la racine du projet, créez un fichier `.env.local` (vous pouvez copier `.env.example`).
2.  Ajoutez vos identifiants Supabase :

    ```env
    VITE_SUPABASE_URL=https://votre-projet.supabase.co
    VITE_SUPABASE_ANON_KEY=votre-cle-anon-publique
    ```

### Étape 3 : Créer les tables (SQL Editor)

Allez dans le **SQL Editor** de votre projet Supabase et exécutez le script suivant pour créer les tables nécessaires :

```sql
-- Table des Voyages
create table trips (
  id bigint generated by default as identity primary key,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null,
  name text not null,
  destination text not null,
  start_date date,
  end_date date,
  status text default 'upcoming'
);

-- Table des Transports
create table transports (
  id bigint generated by default as identity primary key,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null,
  trip_id bigint references trips(id) on delete cascade not null,
  type text, -- Train, Avion, Bus
  departure_city text,
  arrival_city text,
  departure_date date,
  departure_time time,
  arrival_time time,
  carriage text,
  seat text,
  price numeric,
  ticket_number text
);

-- Table des Hébergements
create table accommodations (
  id bigint generated by default as identity primary key,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null,
  trip_id bigint references trips(id) on delete cascade not null,
  platform text, -- Booking, Airbnb, etc.
  name text,
  address text,
  check_in_date date,
  check_out_date date,
  cancellable boolean default false,
  cancellation_date date,
  breakfast_included boolean default false,
  booking_link text,
  price numeric,
  payment_status text -- paid, onsite
);

-- Activation de la sécurité (RLS)
alter table trips enable row level security;
alter table transports enable row level security;
alter table accommodations enable row level security;

-- Politiques d'accès (Pour test/dev : accès public)
-- ATTENTION : Pour une vraie production, configurez l'authentification.
create policy "Public Access Trips" on trips for all using (true);
create policy "Public Access Transports" on transports for all using (true);
create policy "Public Access Accommodations" on accommodations for all using (true);
```

### Étape 4 : Redémarrer l'application

Une fois le fichier `.env.local` créé et les tables configurées, redémarrez votre serveur de développement (`npm run dev`). L'application détectera automatiquement la configuration Supabase et basculera du mode LocalStorage au mode Base de Données.
